# Folaranmi Olaniyi Erastus — Portfolio

Personal AI engineering portfolio for GitHub Pages.

## Publish it

1. In GitHub, open this repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/ (root)**, then save.
5. GitHub will publish the site at:

   `https://olaniyibenaya.github.io/ML-project/`

### Recommended final step

Rename this repository from `ML-project` to `portfolio` in GitHub Settings. The site will then be available at:

`https://olaniyibenaya.github.io/portfolio/`

The page is plain HTML/CSS, so there is no build step and no dependency installation required.
